# Deployment evidence

Only non-secret cache receipts, readiness projections, and bounded deployment
summaries belong here. Model bytes, credentials, kubeconfigs, Terraform state,
signed URLs, license acceptances, and private academic artifact contents do not.
Non-secret private identity and mount metadata may appear only to bind a
fail-closed cross-plane delivery contract; it is never a cache receipt.

`live-staging-cleanup-20260902.json` records the manager-stopped wrong-target
attempt, exact task-owned resources removed, verified H100 context, and the
fail-closed conditions for any future resumption. It is cleanup evidence, not
an artifact-readiness or deployment-success receipt.

`openfold3-components-verification-20260902.json` records the exact upstream
setup revision, S3 identity, local SHA-256, parsed BinaryCIF structure, and
runtime bindings for OpenFold3's required CCD. It is offline source evidence,
not a regional-cache receipt or an H100 qualification.

`protenix-v2-mirror-verification-20260902.json` records the finalized mirror
byte identities, exact v2 source-architecture key/shape match, and a separate
`--network none` Torch structure inspection in an immutable image digest. That
image is explicitly inspection-only and unqualified; the evidence makes no
publisher-byte-equivalence or H100 semantic-readiness claim.

`esm-af3-external-runtime-contract-20260902.json` records the manager-provided
binary inspection of the ESM image's frozen flash-attn wheel, the resulting
binary-compatible Hopper-candidate/Blackwell-blocked boundary, and the exact private
AlphaFold3 parameter identity and `/models` delivery path. It neither contains
private bytes nor makes a public-cache, Blackwell, or semantic-readiness claim.
